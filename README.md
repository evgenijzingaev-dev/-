# Умная корзина 0.12.0

Нативный прототип Android (Kotlin, Android 8.0+). Неофициальное приложение, не связанное с X5. Не требует отдельного API-ключа, собственного сервера, компьютера при использовании или режима Work. Для функций ChatGPT необходим поддерживаемый вход, разрешение использования плана и интернет.

- Независимая синхронизация каталога: пользователь выбирает магазин доставки, приложение обходит видимые категории и обычные элементы догрузки, дедуплицирует карточки и сохраняет отдельный локальный снимок. Поиск по всем загруженным карточкам и подбор рецептов из снимка без новых переходов. Код магазина проверяется при обходе, цена неизвестна при неоднозначной разметке, снимок старше 6 часов требует обновления перед подбором. Полнота не гарантирована; до 400 категорий, 30 000 товаров, 50 циклов на категорию. При ограничении доступа остановка, не обход защиты. API не проверен на реальном адресе.
- При HTTP 403 экспериментальный API отключается на устройстве; приложение предлагает обычную загрузку через сайт. Обход категорий учитывает догрузку при прокрутке главной страницы каталога. Меньший неполный снимок того же магазина не заменяет предыдущую базу.
- Экспериментальный API каталога: прямые HTTPS GET к 5d.5ka.ru, дерево категорий, постраничная загрузка товаров, дедупликация по PLU, обычная цена и наличие, без токенов, подмены отпечатка, обхода блокировок и автоматических повторов. При отказе сервера, повторяющейся странице или смене магазина сохраняется предыдущая база. Наличие скидочных и персональных цен не подтверждено. Если карточка не содержит проверенной ссылки, она доступна для локального расчёта, но не для переноса в корзину. Источник схемы: https://open-inflation.github.io/pyaterochka_api/_modules/pyaterochka_api/endpoints/catalog.html (неофициальный).
- ChatGPT формирует новые блюда, оценивает КБЖУ, использует локальный каталог и предлагает изменения корзины с подтверждением; встроенные рецепты остаются резервным вариантом.
- Семейные профили, дневник, недельное меню из 21 приёма пищи с отдельными порциями, сохранение меню на устройстве. Рекомендации при открытии по согласию, не фоновая служба. Health Connect импортирует вес и шаги взрослого владельца устройства с разрешения и подтверждения.
- Семейные данные передаются OpenAI только при включённой настройке; имя и внутренний идентификатор исключаются. Отключение передачи очищает локальную историю диалога.
- Локальный список, запасы дома, фасовки, цены, бюджет и доставка.
- Главный экран: свободный запрос ChatGPT при подключённом аккаунте, голос через системное распознавание, период, порции и бюджет.
- Импорт обычного списка из ChatGPT, например «Молоко — 500 мл», «Мука 1 кг»; старый формат тоже поддерживается. Нераспознанные строки показываются до подтверждения.
- Экспериментальный пакетный подбор: после выбора адреса на сайте последовательно открывает категории, читает видимые карточки, выбирает совпадающие товары с минимальной стоимостью нужных упаковок без условных акций. Один экран проверки; неизвестные позиции не скрываются. Сохраняет выбранные карточки, названия и фасовки. Подбор не проверен на реальном адресе.
- Экспериментальный перенос выбранных карточек в магазин: после общего подтверждения проверяет точный адрес товара, заголовок, видимую цену, количество и однозначные кнопки. Добавляет только недостающее количество; после каждого нажатия требует наблюдаемое изменение счётчика, иначе останавливается. Не удаляет товары, не оформляет заказ, не гарантирует итог магазина; существующую корзину и адрес проверяет пользователь. Реальная совместимость селекторов ещё не проверена. Неполный план, превышение расчётного бюджета, повторяющиеся карточки и сомнительные цены блокируют перенос.
- КБЖУ из модели являются оценками; соблюдение пищевых ограничений и бюджета требует проверки, особенно при неизвестных ценах. Полностью автоматическая реальная корзина остаётся отдельной задачей. Голос зависит от установленной службы распознавания.
- Экспорт списка и переход в официальный каталог https://5ka.ru/catalog/.
- Каталог и профили сохраняются локально; при запросах ChatGPT необходимые данные отправляются OpenAI. Пароли и SMS приложение не запрашивает.

Экспериментальный встроенный браузер открывает официальный каталог и позволяет войти через официальный интерфейс X5ID (совместимость входа пока не проверена на устройстве). Для ингредиента открывается подходящая категория; кнопка чтения карточек извлекает только видимые названия, цену и фасовку без доступа к токенам. Пользователь выбирает конкретный товар, добавляет его на сайте и подтверждает перенос цены в локальный план. Если карточки не распознаются, доступен ручной ввод. Цены зависят от адреса. Добавлен последовательный сбор непокупленных ингредиентов, фильтр совпадения названий и расчёт стоимости целых упаковок с учётом остатка бюджета. На выбранной карточке экспериментальная кнопка может отправить ровно одно подтверждённое нажатие «В корзину», только если кнопка однозначна; факт добавления проверяет пользователь. Остальные упаковки, условные акции и неоднозначные карточки обрабатываются вручную. Полностью автоматического наполнения, оформления заказа и прямого доступа к API нет; при блокировке не обходить защиту. Chrome имеет отдельную сессию. Экспериментальный read-only API каталога используется только по явной команде пользователя; авторизованная корзина остаётся на сайте.

## Обновление приложения

При запуске проверяется последний стабильный GitHub Release (не чаще раза в 6 часов после успешной проверки), вручную — «Магазин → Проверить обновления». APK скачивается напрямую после подтверждения, проверяются размер, SHA-256 при наличии в метаданных, package ID, versionCode, версия и постоянный сертификат. Установка через системный установщик, пользователь подтверждает её. Нет автоматической установки без согласия.

Для публикации нужен Actions secret `SMARTBASKET_SIGNING` формата `пароль:base64-PKCS12` с alias `smartbasket`; ожидаемый сертификат SHA-256 `3f6dae2efe6ddddd490a71185d5d8fce910e40a39edb8e549b15a6d4b518000f`. Хранить ключ только в секрете и безопасной резервной копии. Без секрета тесты и debug-артефакт работают, выпуск подписанного APK пропускается. После настройки запустить workflow вручную. Каждый новый релиз требует увеличения versionCode и versionName, существующий тег не перезаписывается. Переход с предыдущих debug APK требует разового удаления старой версии (локальные данные будут потеряны; заранее экспортировать список). Последующие APK с той же подписью устанавливаются поверх.

## Сборка
GitHub Actions → Android APK → скачать артефакт SmartBasket-debug → распаковать app-debug.apk. Локально: JDK 17, Gradle 8.7, Android SDK 34. Команда gradle :app:assembleDebug :app:lintDebug.

PR #3 прошёл testDebugUnitTest, assembleDebug и lintDebug (сборка №81). Реальные сценарии входа ChatGPT, Health Connect и корзины магазина на устройстве требуют проверки. Не публиковать персональные данные.
