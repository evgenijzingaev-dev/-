# Умная корзина 0.4.0

Нативный прототип Android (Kotlin, Android 8.0+). Неофициальное приложение, не связанное с X5. Не требует OpenAI API, собственного сервера, компьютера при использовании или режима Work.

- Восемь рецептов, масштабирование порций, объединение ингредиентов.
- Локальный список, запасы дома, фасовки, цены, бюджет и доставка.
- Новый главный экран: запрос обычным языком (локальный ограниченный разбор, не языковая модель), голос через системное распознавание, период, порции и бюджет. Предварительный просмотр меню с объединением ингредиентов.
- Импорт обычного списка из ChatGPT, например «Молоко — 500 мл», «Мука 1 кг»; старый формат тоже поддерживается. Нераспознанные строки показываются до подтверждения.
- Не распознаёт произвольные блюда, сложные пищевые ограничения и не обещает соблюдение бюджета без цен. Полностью автоматическая реальная корзина остаётся отдельной задачей. Голос зависит от установленной службы распознавания.
- Экспорт списка и переход в официальный каталог https://5ka.ru/catalog/.
- Данные только на телефоне; пароли и SMS не запрашиваются.

Экспериментальный встроенный браузер открывает официальный каталог и позволяет войти через официальный интерфейс X5ID (совместимость входа пока не проверена на устройстве). Для ингредиента открывается подходящая категория; кнопка чтения карточек извлекает только видимые названия, цену и фасовку без доступа к токенам. Пользователь выбирает конкретный товар, добавляет его на сайте и подтверждает перенос цены в локальный план. Если карточки не распознаются, доступен ручной ввод. Цены зависят от адреса. Добавлен последовательный сбор непокупленных ингредиентов, фильтр совпадения названий и расчёт стоимости целых упаковок с учётом остатка бюджета. На выбранной карточке экспериментальная кнопка может отправить ровно одно подтверждённое нажатие «В корзину», только если кнопка однозначна; факт добавления проверяет пользователь. Остальные упаковки, условные акции и неоднозначные карточки обрабатываются вручную. Полностью автоматического наполнения, оформления заказа и прямого доступа к API нет; при блокировке не обходить защиту. Chrome имеет отдельную сессию. Неофициальные приватные API не используются.

## Сборка
GitHub Actions → Android APK → скачать артефакт SmartBasket-debug → распаковать app-debug.apk. Локально: JDK 17, Gradle 8.7, Android SDK 34. Команда gradle :app:assembleDebug :app:lintDebug.

Независимый расчётный модуль проверен в исходном проекте (8 групп проверок). Android-сборка требует проверки. Не публиковать персональные данные.
